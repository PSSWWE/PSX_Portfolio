How to Host on GitHub Pages (Free Website Link for Phone & Laptop)
Follow these 4 simple steps to get your own https://username.github.io/psx-portfolio/ link
1Create a Free GitHub Repository
Go to github.com/new, type a Repository name like psx-portfolio, select Public (required for free GitHub Pages), and click Create repository.
2Upload ONLY index.html and portfolio_data.json (No server.py needed!)
On your new repository page, click "uploading an existing file". Drag and drop index.html and portfolio_data.json from your Desktop\Dividend folder, then click Commit changes.
Note about server.py: GitHub Pages is a static website host (it doesn't run Python files). You do not need server.py on GitHub — index.html automatically switches to GitHub Cloud mode when hosted on GitHub Pages! (server.py is only for saving to SQLite/OneDrive when running on your own PC).
3Turn On GitHub Pages (Takes 10 Seconds)
Inside your repository, click Settings (top tab) → click Pages (left sidebar). Under Branch, change None to main and click Save. After ~60 seconds, your live website URL will appear: https://YOUR-USERNAME.github.io/psx-portfolio/!
4Save Changes Remotely from Phone or Any PC
To allow your website to save new trades back to GitHub from your phone: go to GitHub Token Settings, check the repo box, generate a token (`ghp_...`), and paste it into the box on the right!
